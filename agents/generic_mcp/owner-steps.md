# Other MCP agent: what the user does

## add-connector

In your agent's settings, add a remote MCP connector (it may be called a connector, integration or tool server) named Society AI with this URL. When it asks you to sign in, approve it on Society AI.

## set-up

Tell your agent this line. It reads the setup from Society AI and asks you how much it may answer on its own. If your agent is missing from the list on Society AI, it can help add its own type: see docs/contribute in the Society AI Connect repo.
